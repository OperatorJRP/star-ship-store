# 🚀 Starship Store (React Native + Expo)
A simple **Star Wars starship store app** built with React Native (Expo) and Zustand. It allows users to browse starships, search them via the Star Wars API, manage a cart, and place orders — all with a clean UI and smooth UX.

🔥 Demo Link :  https://drive.google.com/file/d/1G2apGABKu0wh8UMnriB_VTi6FNQBfGiK/view?usp=sharing

## 📱 Features
- 🏠 **Home Screen:** Browse starships fetched from [SWAPI](https://swapi.dev)
- 🔍 **Search Screen:** Search starships in real-time using SWAPI's search endpoint
- 🛒 **Cart Screen:** Add/remove starships, choose payment method, view order summary, and place orders
- ⚡ **Global State with Zustand:** Lightweight and efficient global state management
- 🎨 **Reusable Components:** Starship cards, sticky cart bar, and shared UI styles for consistency

## 🧰 Tech Stack
- [React Native](https://reactnative.dev)
- [Expo](https://expo.dev)
- [Zustand](https://github.com/pmndrs/zustand)
- [SWAPI - Star Wars API](https://swapi.dev)
- [React Navigation](https://reactnavigation.org/)
- [@expo/vector-icons](https://docs.expo.dev/guides/icons/)
